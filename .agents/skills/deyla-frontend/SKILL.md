# Изменить экран Deyla

Начни с URL, на котором пользователь выполняет действие. Сопоставь его с маршрутом в `src/App.tsx`, затем проследи импорты до компонента и метода загрузки данных.

- Для `/app/*` найди запись в таблице `ROUTES` файла `src/app/AppRoutes.tsx`. Паттерны там заданы относительно `/app`. При добавлении ссылки внутри кабинета используй `Link` или `navigate` из `src/app/router.tsx`. Для глубоких ссылок открой конечный адрес напрямую и проверь, что при переходе на вход параметр `next` сохраняет путь, строку запроса и фрагмент.
- Для блога проследи путь из `src/app/components/blog/` к `src/app/lib/blogApi.ts`. Управление публикациями находится в `src/pages/Admin/BlogAdmin.tsx`. Для юридических страниц проверь импорт `?raw` из `src/pages/Documents/md_texts/` либо переход на `public/privacy-policy.html` в зависимости от URL.
- Для вычислений в административной аналитике сверь сообщения между `src/pages/Admin/AnalyticsWorkspace.tsx` и `public/analytics-worker.js`. Скрипт `scripts/prepare-analytics-runtime.mjs` запускается перед dev и build, кладёт Pyodide в `public/analytics-runtime/` и скачивает отсутствующие либо повреждённые пакеты с проверкой SHA-256. При сбое загрузки можно отдельно проверить TypeScript через `npm run typecheck`.
- Для локальной проверки API Vite проксирует `/api`, `/auth` и `/health` на `BACKEND_URL` (по умолчанию `http://127.0.0.1:8000`). Опциональный `VITE_DEV_AUTH_BYPASS` в режиме разработки подставляет локальную личность. Для проверки серверной авторизации нужен вход с реальной сессией.
- Проверь изменённый экран на русском и английском, в светлой и тёмной темах и на узком экране. Для диалога проверь клавиатурный фокус при открытии и закрытии. При изменении `src/components/landing/Start.tsx` проверь очистку анимации при уходе со страницы и статичное расположение иконок на мобильном.
